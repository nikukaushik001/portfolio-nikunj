# Nikunj — Portfolio

React + TypeScript + Vite + Tailwind CSS + Framer Motion + React Three Fiber.

## Develop
```
npm install
npm run dev
```

## Build
```
npm run build
npm run preview
```

## Deploy
Push to GitHub, then import the repo on [Vercel](https://vercel.com/new) — it auto-detects Vite.
Framework preset: **Vite**. Build command: `npm run build`. Output dir: `dist`.

Point your custom domain at the Vercel project from Project Settings → Domains.
